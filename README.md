Dynamic network data structures for Julia.

## Overview

DynamicNetworks.jl provides data structures for representing and manipulating dynamic (time-varying) networks. It supports vertex and edge activity spells, time-varying attributes, and network extraction at any time point.

This package is a Julia port of the R `networkDynamic` package from the StatNet collection.

## Installation

Requires Julia 1.12+. DynamicNetworks.jl depends on the unregistered
[NetworkCore.jl](https://github.com/statistical-network-analysis-with-Julia/NetworkCore.jl) package, which must be added first:

```julia
using Pkg
Pkg.add(url="https://github.com/statistical-network-analysis-with-Julia/NetworkCore.jl")
Pkg.add(url="https://github.com/statistical-network-analysis-with-Julia/DynamicNetworks.jl")
```

Some examples below also call `nv`/`ne`/`add_edge!` on the extracted static
networks; those come from NetworkCore.jl (`using NetworkCore`). One guide
example runs a Graphs.jl algorithm on a snapshot; it needs `Pkg.add("Graphs")`.

For development, clone the ecosystem repositories side by side (each
`<Pkg>.jl` directory next to its siblings, so the `[sources]` path
dependencies resolve) and `Pkg.develop(path="DynamicNetworks.jl")` into your
environment; the organisation site's `tools/prepare_workspace.jl` builds such
a workspace with every package and the extras the examples use.

## Features

- **Activity spells**: Track when vertices and edges are active, with R
  networkDynamic's semantics: half-open spells, point spells, elements with no
  spells active by default (`active_default=true`), spells merged on activation
- **Time-varying attributes**: Attributes that change over time
- **Network extraction**: Get network state at any time point or over an interval
- **Spell operations**: Add, remove, deactivate, merge, and query spells
- **Panels of static networks**: `DynamicNetwork([net1, net2, net3])` is R's
  `networkDynamic(network.list = ...)`, with its discrete spells
- **Validated against R**: golden fixtures generated by networkDynamic 0.12
  (80 random spell cases, 40 random panels) must match exactly

## Quick Start

```julia
using DynamicNetworks

# Create dynamic network with 5 vertices
dnet = DynamicNetwork{Int, Float64}(5;
    observation_start=0.0,
    observation_end=10.0
)

# Activate vertices and edges
activate!(dnet, 0.0, 5.0; vertex=1)
activate!(dnet, 0.0, 5.0; vertex=2)
activate!(dnet, 1.0, 4.0; edge=(1, 2))

# Check activity
is_active(dnet, 2.0; edge=(1, 2))  # true
is_active(dnet, 6.0; edge=(1, 2))  # false

# Vertices 3-5 have no spells: active by default, as in R
is_active(dnet, 2.0; vertex=3)                        # true
is_active(dnet, 2.0; vertex=3, active_default=false)  # false

# Extract network at time 2.0 (vertices 1-5 active, one edge)
snapshot = network_extract(dnet, 2.0)
```

## Activity Spells

<!-- skip-check -->
```julia
# Add activity spell
add_spell!(dnet, Spell(0.0, 5.0); vertex=1)
add_spell!(dnet, Spell(1.0, 3.0); edge=(1, 2))

# Convenience function
activate!(dnet, onset, terminus; vertex=v)
activate!(dnet, onset, terminus; edge=(i, j))

# Activate multiple elements
activate_vertices!(dnet, [1, 2, 3], 0.0, 10.0)
activate_edges!(dnet, [(1,2), (2,3)], 0.0, 5.0)

# Remove spell
remove_spell!(dnet, spell; vertex=v)

# Cut activity out of [onset, terminus) (an element with no spells is
# active on (-Inf, Inf) and is cut the same way)
deactivate!(dnet, onset, terminus; vertex=v)

# activate!/add_spell! merge overlapping and adjacent spells on insertion, as
# R's activate.* do; merge_spells! is needed only after add_spell!(...; merge=false)
add_spell!(dnet, Spell(0.0, 5.0); vertex=1, merge=false)
merge_spells!(dnet; vertex=v)
merge_spells!(dnet)            # every vertex and edge
```

## Querying Activity

```julia
# Is element active at a point?
is_active(dnet, 2.0; vertex=1)
is_active(dnet, 2.0; edge=(1, 2))

# Is element active during interval?
is_active(dnet, 1.0, 3.0; vertex=1, rule=:any)   # Active at any point
is_active(dnet, 1.0, 3.0; vertex=1, rule=:all)   # Active throughout (adjacent spells count)

# Elements with no spells count as active unless you say otherwise
is_active(dnet, 2.0; vertex=4, active_default=false)

# Get all active elements at a time
active_vertices(dnet, 2.0)
active_edges(dnet, 2.0)

# Get the stored spells for an element
spells = get_spells(dnet; vertex=1)
spells = when_vertex(dnet, 1)
spells = when_edge(dnet, 1, 2)

# R's get.vertex.activity view: (-Inf, Inf) for an element with no spells
get_vertex_activity(dnet, 4)

# All spell boundaries (R's get.change.times)
get_change_times(dnet)
```

## Network Extraction

```julia
# Extract snapshot at time point
snapshot = network_extract(dnet, 2.0)

# Extract during interval
snapshot = network_extract(dnet, 1.0, 3.0; rule=:any)

# Extract sequence of snapshots
snapshots = network_slice(dnet, [1.0, 2.0, 3.0, 4.0])

# Collapse to static: R's network.collapse (ties ever active between
# ever-active vertices), but keeping every vertex so IDs are stable
static = network_collapse(dnet)
```

An extracted edge needs both endpoints active. Without
`retain_all_vertices=true`, inactive vertices are dropped and the survivors
renumbered; their original IDs are in the `:vertex_pid` vertex attribute.

## Time-Varying Attributes

<!-- skip-check -->
```julia
# Set attribute active during spell
set_vertex_attribute_active!(dnet, v, :status, "infected", 2.0, 5.0)

# Get attribute at time
status = get_vertex_attribute_active(dnet, v, :status, 3.0)

# Edge attributes
set_edge_attribute_active!(dnet, i, j, :weight, 0.5, 1.0, 4.0)
w = get_edge_attribute_active(dnet, i, j, :weight, 2.0)
```

## Conversion

```julia
# Static to dynamic (NetworkCore.jl network -> DynamicNetwork)
using NetworkCore
static_net = network(5)
add_edge!(static_net, 1, 2)
dnet2 = as_dynamic_network(static_net; onset=0.0, terminus=10.0)

# A panel of networks observed at waves 0, 1, 2 (R's
# networkDynamic(network.list = list(w1, w2, w3))): each wave holds for one
# time step, ties present in consecutive waves have one merged spell, and the
# observation window is (0, 3)
w2 = copy(static_net); add_edge!(w2, 2, 3)
panel = DynamicNetwork([static_net, w2, static_net])
get_spells(panel; edge=(2, 3))     # [Spell[1.0, 2.0)]

# Get timing info
info = get_timing_info(dnet2)
# (observation_period, data_start, data_end, n_vertex_spells, n_edge_spells)

# Ensure edge activity consistent with vertex activity
# (R's reconcile.edge.activity(mode = "reduce.to.vertices"))
reconcile_activity!(dnet2)
```

The observation window is the one given at construction (or by
`set_observation_period!`, `as_dynamic_network` or the panel constructor).
When none was given, `get_observation_period` returns `nothing`, as R's
`net.obs.period` is `NULL`: nothing is derived from the data. TSNA.jl and
NDTV.jl then apply tsna's and ndtv's own rules for a network without a
window (lifetimes over the whole time axis, series and animations over the
closed range of `get_change_times`), and ask for a window where those rules
would fall back to a placeholder range.

## Spell Type

```julia
# Create spell
s1 = Spell(0.0, 5.0)
s2 = Spell(3.0, 8.0; onset_censored=true)  # May have started earlier

# Spell operations
spell_overlap(s1, s2)   # Do spells overlap? -> true
spell_duration(s1)      # Duration -> 5.0
spell_duration(Spell(1.0, Inf))           # Inf
spell_duration(Spell(typemin(Int), 4))    # typemax(Int): unbounded, never an overflow
```

On integer and calendar time axes, which have no infinities, `typemin` and
`typemax` stand for `-Inf` and `Inf` (`DynamicNetworks.unbounded_spell`); a
spell reaching either has unbounded duration.

## Coming from R networkDynamic

| R networkDynamic | DynamicNetworks.jl | Difference |
|:--|:--|:--|
| `activate.vertices`/`activate.edges` | `activate!`, `activate_vertices!`, `activate_edges!`, `add_spell!` | one spell per call; same merging |
| `deactivate.vertices`/`deactivate.edges` | `deactivate!` | — |
| `is.active(..., active.default=)` | `is_active(...; active_default=)` | one element per call; no `earliest`/`latest` rules |
| `get.vertex.activity`/`get.edge.activity` | `get_vertex_activity`/`get_edge_activity` | one element per call |
| — | `get_spells`, `when_vertex`, `when_edge` | Julia-only: the stored spells (empty for an element with no spells) |
| `get.change.times` | `get_change_times` | — |
| `networkDynamic(network.list = ...)` | `DynamicNetwork(networks; onsets, termini, start)` | panels matched by vertex position (no `vertex.pid`); one observation window |
| `net.obs.period` | `get_observation_period`/`set_observation_period!` | one window; `nothing` when unset, as R's `NULL` |
| `network.extract` | `network_extract` | no `trim.spells`; `vertex.pid` → `:vertex_pid` |
| `network.collapse` | `network_collapse` | keeps every vertex; no attribute aggregation |
| `get.networks` | `network_slice` | explicit instants |
| `reconcile.edge.activity(mode="reduce.to.vertices")` | `reconcile_activity!` | other modes not implemented |
| `activate.vertex.attribute`/`get.vertex.attribute.active` (and edge) | `set_vertex_attribute_active!`/`get_vertex_attribute_active` (and edge) | latest-set value wins on overlap |
| `as.networkDynamic(net)` | `as_dynamic_network(net; onset, terminus)` | gives every element the spell `[onset, terminus)` |

The full table, with every networkDynamic export, is in the documentation
(*Coming from R*). Stored spells, `network.extract` (instants and intervals,
both rules), `network.collapse` edges and `reconcile.edge.activity` are
checked against R networkDynamic 0.12 by the golden fixture
`test/fixtures/spell_semantics.toml` (80 random cases, generated by
`test/fixtures/r/spell_semantics.R`), and the panel constructor by
`test/fixtures/panel_semantics.toml` (40 random panels, from
`test/fixtures/r/panel_semantics.R`); exact agreement is required.

## Not implemented

These R networkDynamic features have no counterpart (kept in sync with the
CHANGELOG "Known limitations"):

- time-varying network attributes (`activate.network.attribute`) and attribute deactivation;
- `network.collapse` attribute aggregation (`activity.count`, `activity.duration`, TEA summaries); the `earliest`/`latest` rules;
- `trim.spells`; `reconcile.edge.activity(mode="match.to.vertices")`; `reconcile.vertex.activity`;
- spell data-frame import/export (`networkDynamic(edge.spells=, vertex.spells=)`, `as.data.frame.networkDynamic`), `read.son`;
- persistent IDs beyond the `:vertex_pid` attribute (`vertex.pid`/`edge.pid` management), so panels with different vertex sets cannot be matched;
- `net.obs.period` with several observation spells and its time-unit metadata;
- active-subset helpers (`get.neighborhood.active`, `is.adjacent.active`, `get.dyads.active`, `network.dyadcount.active`, `add.vertices.active`, ...), the age functions (`edges.age.at`, ...), `adjust.activity`, `delete.edge.activity`/`delete.vertex.activity`, `when.edge.attrs.match`, `activate.edge.value`, `search.spell`, `spells.hit`, `%t%`/`%k%`;
- hyperedges and multiplex edges (not represented by NetworkCore.jl).
